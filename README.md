# BOOST Advanced Manufacturing Workplace Skills Challenge — v1.0

This GitHub release adapts the proven BOOST Healthcare Workplace Skills Challenge engine for Advanced Manufacturing.

## Included
- Employer-demand opening visual and narration
- 8 clickable Lightcast employer-demand skill cards
- 5 instructional component-recognition items per skill with Try Again / teaching feedback
- 8 randomized workplace-judgment scenarios with balanced, plausible distractors
- Scenario-specific image and audio assets
- 11-item Technical Exposure section, including AI / AI-enabled tools
- Before/after fit check, reflection, coaching cues, exploration signals, and printable snapshot

## Canonical asset paths
All files use lowercase names, underscores, and matching image/audio stems.

## Important
This is a career-alignment learning activity, not a hiring assessment, certification exam, or determination of manufacturing qualification.
